## Week 1 - History
- Each glyph usually represents a syllable (ki, sal, …)
- The Epic of Gilgamesh talks about pride and hubris, friendship and death
- The printing press contributed significantly to the Protestant Reformation which split the Catholic Church

## Week 2 - Bits and Bytes
- “bit” is short for “Binary Digit”
- Volatile memory is used as short-term working memory, it’s usually much faster but much more expensive
- When you want to say a binary number 10 – spell out the digits “binary one zero” as if you are talking over a radio

## Week 3 - Markup Languages
- Alphanumeric characters – letters and digits like A, b, c … and 0 to 9
- Non-alphanumeric characters are everything else – Examples: {[(+)]};-) sometimes shortened as non-alpha
- JSON stands for JavaScript Object Notation

## Week 4 - Keyboards & Editors
- QWERTZ is common in Germany, Eastern Europe and Portugal
- An IDE includes an editor + many other tools integrated into it
- Wildcard characters are characters that will match any character or sequence of characters in a search

## Week 5 - CLI
- SSH stands for “Secure Shell” because it’s encrypted, in contrast to older options like “telnet” which is rarely used now 
- Command line is great for working remotely – only short pieces of text are sent over the network 
- Tmux Stands for “Terminal Multiplexer”
